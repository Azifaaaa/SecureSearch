⚠ Cryptographic keys are managed via environment variables and the .env file. They are NEVER shown in this interface and are NEVER stored in the database.
🔑 Key Setup Guide
  1. Generate keys: python scripts/generate_keys.py
  2. Copy the output lines into your .env file
  3. Restart the Flask application
  4. Keys are loaded once at startup from environment variables
  5. NEVER commit .env to Git
  6. Back up your keys in a secure password manager or encrypted file
⚠ If you lose your ENCRYPTION_KEY, all stored records become permanently unreadable. If you lose your SEARCH_KEY, the entire search index becomes invalid.
🌍 Environment Variables
VariablePurposeRequired
FLASK_SECRET_KEYFlask session signingYes
ENCRYPTION_KEY_B64AES-256-GCM encryption/decryptionYes
SEARCH_KEY_B64HMAC search token generationYes
INTEGRITY_KEY_B64HMAC integrity verificationYes
STORAGE_MODElocal or cloudYes
DATABASE_URLSQLite or PostgreSQL URLOptional
SUPABASE_URLSupabase project URLCloud only
SUPABASE_SERVICE_KEYSupabase service-role keyCloud only
SUPABASE_DB_URLSupabase PostgreSQL connectionCloud only
