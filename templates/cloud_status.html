📋 Storage Mode Guide

LOCAL Mode

  • No cloud credentials required
  • Encrypted objects stored in storage/encrypted_objects/
  • SQLite database (securesearch_local.db)
  • Perfect for development and testing
  • Set STORAGE_MODE=local in .env

CLOUD Mode (Supabase)

  • Requires Supabase project credentials
  • Encrypted objects in private Storage bucket
  • PostgreSQL database in Supabase
  • Service-role key NEVER sent to browser
  • Set STORAGE_MODE=cloud and configure SUPABASE_URL, SUPABASE_SERVICE_KEY, SUPABASE_DB_URL
