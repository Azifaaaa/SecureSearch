🔍 Exact Match Search
🔄 Search Workflow
  1. Enter a field and value to search for
  2. Backend generates HMAC token for the query
  3. Token compared against stored index (no plaintext in DB)
  4. Matching record IDs retrieved
  5. Ciphertexts fetched from storage
  6. Records decrypted and returned
📊 Numeric Range Search
🪣 Bucket Index Workflow
  1. Enter numeric condition (e.g. temperature > 30°C)
  2. Backend determines affected 1°C buckets
  3. HMAC tokens generated for each bucket
  4. Candidate record IDs retrieved via bucket token index
  5. Each candidate fetched and decrypted
  6. Exact numeric comparison performed post-decryption
  7. Only truly matching records returned
